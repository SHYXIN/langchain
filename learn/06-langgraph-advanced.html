进阶 1: MemorySaver — 状态持久化

LangGraph 默认不保存状态。MemorySaver 让图在每次执行后自动保存快照。

from langgraph.checkpoint.memory import MemorySaver

# 创建检查点存储器
memory = MemorySaver()

# 编译时传入 checkpointer
app = graph.compile(checkpointer=memory)

# 运行时传入 config（同一 thread_id 共享状态）
config = {"configurable": {"thread_id": "user-123"}}

# 第 1 轮
app.invoke({"messages": [("human", "我叫小明")]}, config)

# 第 2 轮 — 自动加载历史
app.invoke({"messages": [("human", "我叫什么名字？")]}, config)
# AI 会记得"小明"！

时间旅行（Time Travel）

利用保存的历史快照，可以回到任意历史状态重新执行：

# 获取所有历史状态
history = list(app.get_state_history(config))
print(f"共 {len(history)} 个快照")

# 回到第 2 个快照重新执行
checkpoint = history[2]
result = app.invoke(None, checkpoint.config)

进阶 2: interrupt/Command — 人工介入

interrupt() 让图在任意节点暂停执行，等待外部输入后通过 Command(resume=...) 恢复。

┌──────────┐ ┌──────────────┐ ┌──────────────┐ │ 生成内容 │───→│ interrupt() │───→│ 恢复执行 │ │ │ │ 【暂停等待】 │ │ Command(...) │ └──────────┘ └──────────────┘ └──────────────┘ │ ▼ ┌──────────────┐ │ 人工审核 UI │ │ 批准 / 拒绝 │ └──────────────┘
from langgraph.types import interrupt, Command

def review_node(state):
    # 暂停执行，向外部发送数据
    result = interrupt({
        "question": "是否批准？",
        "content": state["content"]
    })
    return {"approved": result["approved"]}

# 第 1 步：运行到 interrupt 处暂停
try:
    result = app.invoke(input_data, config)
except:
    # 图已暂停

# 第 2 步：人工审核后恢复
result = app.invoke(Command(resume={"approved": True}), config)

进阶 3: task/entrypoint — 函数式工作流

LangGraph 1.x 引入了函数式 API，用 @task 和 @entrypoint 替代手动定义 StateGraph：

from langgraph.func import task, entrypoint
from langgraph.checkpoint.memory import MemorySaver

@task
def search_task(topic: str) -> str:
    """搜索信息"""
    return f"搜索结果: {topic}"

@task
def analyze_task(info: str) -> str:
    """分析信息"""
    return f"分析: {info}"

@entrypoint(checkpointer=MemorySaver())
def my_workflow(inputs: dict) -> dict:
    # 像写普通函数一样编排工作流
    search_result = search_task(inputs["topic"]).result()
    analysis = analyze_task(search_result).result()
    return {"result": analysis}

# 使用
result = my_workflow.invoke(
    {"topic": "LangChain"},
    config={"configurable": {"thread_id": "wf-001"}}
)
💡 函数式 API 的优势：
  • 不需要手动定义 TypedDict State
  • 不需要手动添加节点和边
  • 代码更简洁，像写普通 Python 函数
  • 自动支持 checkpointing

进阶 4: 多 Agent 协作

LangGraph 支持多种多 Agent 协作模式：

Supervisor 模式

┌─────────────┐ │ Supervisor │ ← 分配任务 └──────┬──────┘ │ ┌────┴────┐ ▼ ▼ ┌──────┐ ┌──────┐ │Agent │ │Agent │ ← 执行任务 │ A │ │ B │ └──────┘ └──────┘

Pipeline 模式（流水线）

┌──────────┐ ┌──────────┐ ┌──────────┐ │ Researcher│───→│ Writer │───→│ Reviewer │──→ END │ 研究员 │ │ 写手 │ │ 审核 │ └──────────┘ └──────────┘ └──────────┘
class TeamState(TypedDict):
    messages: Annotated[list, add_messages]
    topic: str
    research_result: str
    final_article: str

def researcher_node(state: TeamState) -> dict:
    """研究员：收集信息"""
    response = llm.invoke(f"研究主题：{state['topic']}")
    return {"research_result": response.content}

def writer_node(state: TeamState) -> dict:
    """写手：撰写文章"""
    response = llm.invoke(f"根据以下要点写文章：\n{state['research_result']}")
    return {"final_article": response.content}

# 构建流水线
graph = StateGraph(TeamState)
graph.add_node("researcher", researcher_node)
graph.add_node("writer", writer_node)
graph.add_edge(START, "researcher")
graph.add_edge("researcher", "writer")
graph.add_edge("writer", END)

app = graph.compile()
result = app.invoke({"topic": "LangChain 的应用场景"})
