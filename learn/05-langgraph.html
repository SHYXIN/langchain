1. LangGraph 是什么？

LangGraph 是 LangChain 的工作流编排引擎，用于构建有状态的、多步骤的 AI 应用。它用图（Graph）的方式来组织代码：

┌─────────────────────────────────────────────────┐ │ LangGraph 状态图 │ │ │ │ ┌───────┐ ┌───────┐ ┌───────┐ │ │ │ Node A │───→│ Node B │───→│ Node D │──→ END│ │ └───────┘ └───────┘ └───────┘ │ │ │ │ │ ▼ │ │ ┌───────┐ │ │ │ Node C │──→ END │ │ └───────┘ │ │ │ │ 每个节点读/写 State，边控制流转方向 │ └─────────────────────────────────────────────────┘

核心概念

概念说明类比
State图中流动的数据全局变量
Node处理状态的函数函数/步骤
Edge节点之间的连接goto / if-else
START图的入口main()
END图的出口return

2. State（状态）

State 是图中所有节点共享的数据，用 TypedDict 定义结构：

from typing import TypedDict, Annotated
from langchain_core.messages import BaseMessage
from langgraph.graph.message import add_messages

# 定义 State 结构
class MyState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]  # 消息列表（自动追加）
    step: str      # 当前步骤
    count: int     # 计数器
    result: str    # 结果

# add_messages 的作用：
# 当节点返回 {"messages": [new_msg]} 时，
# 新消息会自动追加到现有列表，而不是替换
add_messages 是 LangGraph 的关键机制 — 它让消息列表自动累积，非常适合对话场景。

3. Node（节点）

节点是一个函数，接收 State，返回要更新的字段：

def my_node(state: MyState) -> dict:
    # 读取 state
    messages = state["messages"]
    count = state["count"]

    # 处理逻辑
    new_count = count + 1

    # 返回要更新的字段（部分更新）
    return {
        "count": new_count,
        "step": "processed",
    }

4. 构建图

4.1 最简单的图

from langgraph.graph import StateGraph, START, END

# 创建图
graph = StateGraph(MyState)

# 添加节点
graph.add_node("node_a", node_a_func)
graph.add_node("node_b", node_b_func)

# 添加边（普通边）
graph.add_edge(START, "node_a")      # 入口 → A
graph.add_edge("node_a", "node_b")   # A → B
graph.add_edge("node_b", END)        # B → 出口

# 编译图
app = graph.compile()

# 运行
result = app.invoke({"messages": [], "count": 0})

4.2 条件分支

def router(state: MyState) -> str:
    # 根据状态决定走哪条路
    if state["count"] < 3:
        return "continue"
    else:
        return "stop"

graph.add_conditional_edges(
    "node_a",
    router,
    {
        "continue": "node_a",  # 循环回自己
        "stop": END,          # 结束
    }
)

5. 完整的 AI Agent 工作流

这是 LangGraph 最经典的用法 — ReAct Agent：

┌──────────┐ ┌──────────────┐ ┌──────────┐ │ │ │ LLM Node │ │ │ │ START │───→│ (思考+决策) │───→│ END │ │ │ └──────┬───────┘ │ │ └──────────┘ │ └──────────┘ │ 需要调用工具? ▼ ┌──────────────┐ │ Tool Node │──→ 结果返回 LLM │ (执行工具) │ └──────────────┘ 
from langgraph.prebuilt import ToolNode, tools_condition
from langgraph.graph import StateGraph, START, END, MessagesState
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool

# 1. 定义工具
@tool
def search(query: str) -> str:
    """搜索信息"""
    return f"搜索结果: {query}"

tools = [search]

# 2. 创建 LLM（绑定工具）
llm = ChatOpenAI(model="gpt-4o").bind_tools(tools)

# 3. 定义节点
def llm_node(state: MessagesState):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}

# 4. 构建图
graph = StateGraph(MessagesState)
graph.add_node("llm", llm_node)
graph.add_node("tools", ToolNode(tools))

# 5. 添加边
graph.add_edge(START, "llm")
graph.add_conditional_edges(
    "llm",
    tools_condition,  # 内置条件：有工具调用 → tools，否则 → END
)
graph.add_edge("tools", "llm")  # 工具执行完 → 回到 LLM

# 6. 编译并运行
app = graph.compile()
result = app.invoke({"messages": ["LangChain 是什么？"]})

6. Human-in-the-Loop

LangGraph 可以在任意节点暂停，等待人工输入：

from langgraph.types import interrupt

def review_node(state):
    # 暂停，等待人工审核
    review_result = interrupt({
        "content": state["content"],
        "message": "请审核以上内容"
    })
    return {"approved": review_result["approved"]}

# 运行时，图会在 interrupt 处暂停
# 人工输入后，通过 Command(resume=...) 继续
from langgraph.types import Command
result = app.invoke(Command(resume={"approved": True}))

7. LangGraph vs 普通链式调用

特性普通 ChainLangGraph
控制流线性（A→B→C）图（分支、循环）
条件判断❌✅ add_conditional_edges
循环❌✅ 条件边指回自身
人工介入❌✅ interrupt
状态管理手动自动（State）
适用场景简单流程复杂工作流

8. 实战练习

练习 1：构建一个简单的问答工作流

# 要求：START → 生成问题 → LLM 回答 → END
from langgraph.graph import StateGraph, START, END, MessagesState
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o")

def answer_node(state: MessagesState):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}

graph = StateGraph(MessagesState)
graph.add_node("answer", answer_node)
graph.add_edge(START, "answer")
graph.add_edge("answer", END)

app = graph.compile()
result = app.invoke({"messages": ["什么是 Python？"]})
print(result["messages"][-1].content)

练习 2：构建一个带重试逻辑的工作流

class RetryState(TypedDict):
    messages: Annotated[list, add_messages]
    retries: int
    max_retries: int

def process_node(state: RetryState):
    try:
        # 尝试处理...
        response = llm.invoke(state["messages"])
        return {"messages": [response]}
    except:
        return {"retries": state["retries"] + 1}

def should_retry(state: RetryState):
    if state["retries"] < state["max_retries"]:
        return "retry"
    return "give_up"

graph = StateGraph(RetryState)
graph.add_node("process", process_node)
graph.add_conditional_edges("process", should_retry, {
    "retry": "process",
    "give_up": END,
})
graph.add_edge(START, "process")
