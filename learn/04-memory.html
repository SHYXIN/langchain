1. 为什么需要 Memory？

LLM 本身是无状态的 — 每次调用都是独立的，不记得之前的对话。

❌ 没有 Memory

用户: "我叫小明"
AI: "你好小明！"
用户: "我叫什么？"
AI: "我不知道你的名字"
← 忘了！
✅ 有 Memory

用户: "我叫小明"
AI: "你好小明！"
用户: "我叫什么？"
AI: "你叫小明"
← 记住了！

2. 手动管理 Memory

最简单的方式：自己维护消息列表，每次调用时传入完整历史。

from langchain_core.messages import HumanMessage, AIMessage
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="LongCat-2.0-Preview", ...)

# 手动维护对话历史
history = []

# 第 1 轮
history.append(HumanMessage(content="我叫小明"))
response = llm.invoke(history)
history.append(response)  # 保存 AI 回复

# 第 2 轮 — 带上完整历史
history.append(HumanMessage(content="我叫什么名字？"))
response = llm.invoke(history)  # AI 能记住小明！
print(response.content)  # "你叫小明！"

3. 滑动窗口 Memory

当对话很长时，保留所有历史会超出模型的上下文窗口。滑动窗口只保留最近 K 条消息。

对话历史: [msg1, msg2, msg3, msg4, msg5, msg6, msg7, msg8] ↑ 只保留最近 4 条 窗口大小 K=4 → 结果: [msg5, msg6, msg7, msg8] 优点: 简单高效，内存占用可控 缺点: 丢失早期信息（msg1~msg4 被丢弃）
class SlidingWindowMemory:
    def __init__(self, window_size=6):
        self.window_size = window_size
        self.messages = []

    def add_message(self, message):
        self.messages.append(message)

    def get_messages(self):
        # 只返回最近 K 条
        return self.messages[-self.window_size:]

# 使用
memory = SlidingWindowMemory(window_size=4)
# 添加 10 条消息后...
memory.get_messages()  # 只返回最后 4 条

4. 摘要 Memory

将旧的对话摘要为一条消息，保留关键信息的同时减少 token 消耗。

原始历史（8 条消息）: 用户: "我叫小明，今年 25 岁" AI: "你好小明！" 用户: "我喜欢打篮球和编程" AI: "很棒的爱好！" 用户: "我在北京工作，是一名软件工程师" AI: "北京是个很棒的城市！" 用户: "我正在学习 LangChain" AI: "LangChain 很有用！" ↓ 压缩为 ↓ 摘要后（5 条消息）: 系统: "对话历史摘要：小明今年25岁，喜欢打篮球和编程。" 用户: "我在北京工作，是一名软件工程师" ← 保留最近几条 AI: "北京是个很棒的城市！" 用户: "我正在学习 LangChain" AI: "LangChain 很有用！"
class SummaryMemory:
    def __init__(self, llm, summary_threshold=6):
        self.llm = llm
        self.summary_threshold = summary_threshold
        self.messages = []
        self.summary = ""

    def get_messages(self):
        if len(self.messages) <= self.summary_threshold:
            return self.messages

        # 旧消息 → 摘要
        old = self.messages[:-self.summary_threshold]
        recent = self.messages[-self.summary_threshold:]
        self.summary = self._summarize(old)

        # 返回: 摘要 + 最近消息
        result = [SystemMessage(content=f"对话摘要：{self.summary}")]
        result.extend(recent)
        return result

5. 记忆策略对比

策略优点缺点适用场景
全量记忆信息完整token 消耗大短对话（<10轮）
滑动窗口简单高效丢失早期信息中等长度对话
摘要记忆保留关键信息摘要可能丢失细节长对话（>10轮）
