# 模块 4: Memory（记忆管理）

## 学习目标
完成本模块后，你将能够：
1. 理解 LangChain 中 Memory 的概念和类型
2. 学会使用不同的记忆策略管理对话历史
3. 构建一个有记忆的多轮对话系统

---

## 1. 什么是 Memory？

在对话应用中，**Memory** 是指系统记住之前对话内容的能力。没有 Memory，AI 每次回答都是独立的，不记得之前说过什么。

```
无 Memory:
  用户: "我叫小明"
  AI: "你好，小明！"
  用户: "我叫什么？"
  AI: "我不知道你的名字"  ← 忘记了！

有 Memory:
  用户: "我叫小明"
  AI: "你好，小明！"
  用户: "我叫什么？"
  AI: "你叫小明"  ← 记住了！
```

## 2. Memory 的类型

### 2.1 短期记忆（对话历史）

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| `ChatMessageHistory` | 保存所有消息 | 短对话 |
| `ConversationBufferWindowMemory` | 只保留最近 K 轮 | 控制上下文长度 |
| `ConversationSummaryMemory` | 自动总结历史 | 长对话 |

### 2.2 长期记忆（持久化存储）

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| `InMemoryStore` | 内存存储 | 开发测试 |
| `VectorStoreRetrieverMemory` | 向量检索记忆 | 按语义查找相关记忆 |

## 3. LangChain v1 的 Memory 机制

LangChain v1 使用 **checkpoint** 机制来管理记忆：

```
┌─────────────────────────────────────────────────┐
│              Checkpoint 记忆机制                   │
│                                                 │
│  每次对话 → 保存状态（Checkpoint）                  │
│       ↓                                         │
│  下次对话 → 恢复状态 → 继续对话                    │
│                                                 │
│  状态包含:                                       │
│    - messages: 对话历史                           │
│    - user_info: 用户信息                          │
│    - metadata: 元数据                            │
└─────────────────────────────────────────────────┘
```
