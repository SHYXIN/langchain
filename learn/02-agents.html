1. 什么是 Agent？

Agent（智能体）是一个能够自主决策和调用工具的 LLM 应用。

与普通链式调用不同，Agent 可以：

  • 根据用户输入决定是否需要调用工具
  • 选择合适的工具并传入参数
  • 根据工具返回结果继续思考或给出最终答案
  • 在工具调用和推理之间循环，直到完成任务

2. ReAct 模式

Agent 的核心执行模式是 ReAct（Reasoning + Acting）：

┌─────────────────────────────────────────────────────┐ │ Agent 执行循环（ReAct 模式） │ │ │ │ 用户输入 ──→ [思考 Thought] │ │ │ │ │ ▼ │ │ [决定行动 Action] │ │ │ │ │ ▼ │ │ [执行工具 Tool] │ │ │ │ │ ▼ │ │ [观察结果 Observation] │ │ │ │ │ ▼ │ │ 是否完成？──否──→ 继续思考 │ │ │ │ │ 是 │ │ ▼ │ │ 输出最终答案 │ └─────────────────────────────────────────────────────┘

3. 定义工具（Tools）

工具是 Agent 可以调用的函数。使用 @tool 装饰器定义：

from langchain_core.tools import tool

@tool
def calculator(expression: str) -> str:
    """计算数学表达式。支持 +, -, *, /, **, sqrt() 等。"""
    try:
        result = eval(expression)
        return f"{expression} = {result}"
    except Exception as e:
        return f"计算错误: {e}"

@tool
def get_weather(city: str) -> str:
    """获取指定城市的天气信息。"""
    weather_data = {
        "北京": {"温度": "22°C", "天气": "晴"},
        "上海": {"温度": "25°C", "天气": "多云"},
    }
    data = weather_data.get(city, {"温度": "未知", "天气": "未知"})
    return f"{city}: {data['天气']}, {data['温度']}"
💡 关键点：
  • docstring 非常重要！Agent 靠它理解工具的用途
  • 类型注解 帮助 Agent 知道参数类型
  • 函数名应该清晰表达功能

4. 创建 Agent

LangChain v1 使用 create_agent 创建 Agent：

from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain_core.prompts import ChatPromptTemplate

# 1. 创建 LLM
llm = ChatOpenAI(
    model="LongCat-2.0-Preview",
    api_key="your-api-key",
    base_url="https://api.longcat.chat/openai",
)

# 2. 定义工具列表
tools = [calculator, get_weather]

# 3. 定义系统提示词
system_prompt = "你是一个有帮助的助手，可以使用工具回答问题。"

# 4. 创建 Agent
agent = create_agent(
    model=llm,
    tools=tools,
    system_prompt=system_prompt,
)

# 5. 调用 Agent
result = agent.invoke({
    "messages": [("user", "北京天气怎么样？")]
})
print(result["messages"][-1].content)

5. Agent 工作原理详解

当 Agent 收到用户输入时，内部执行以下步骤：

1
LLM 思考：分析用户意图，决定是否需要调用工具
2
工具调用：如果需要，生成工具名称和参数
3
执行工具：LangGraph 自动执行工具函数
4
结果回传：工具返回结果作为 ToolMessage 加入对话
5
再次思考：LLM 根据工具结果决定下一步（继续调用工具 or 给出答案）

7. Agent vs 普通 Chain

特性普通 ChainAgent
执行流程固定顺序动态决策
工具调用不支持自动选择和调用
循环不支持支持（ReAct 循环）
适用场景简单任务（翻译、摘要）复杂任务（问答、操作）
延迟低（1 次 LLM 调用）高（多次 LLM 调用）
